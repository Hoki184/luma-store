# LUMA — premium essentials

Навчальний frontend-проєкт інтернет-магазину одягу, створений на HTML, CSS і JavaScript.

## Live demo

https://hoki184.github.io/luma-store/

## Можливості

- адаптивна головна сторінка;
- каталог товарів;
- пошук і фільтрація за категоріями;
- кошик із додаванням, видаленням і очищенням товарів;
- збереження кошика в `localStorage`;
- форма оформлення замовлення;
- мобільне меню;
- адаптація під телефон і планшет.

## Технології

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Запуск локально

1. Клонуй репозиторій:

   ```bash
   git clone https://github.com/Hoki184/luma-store.git
   ```

2. Відкрий папку проєкту у VS Code.
3. Запусти `index.html` через розширення Live Server.

## Важливо

Це frontend-демо для навчання. Форма замовлення поки не підключена до сервера, бази даних або платіжної системи.
